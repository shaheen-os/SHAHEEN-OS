# Assets - Images

This directory contains image assets for the SHAHEEN-OS portfolio website.

## Current images

All images are currently hosted externally from PostImg and are referenced via direct URLs in the website and README.

## Local image storage

Future local images may be stored in this directory.

## Image optimization guidelines

When adding local images:
- Use descriptive filenames
- Optimize for web (JPEG for photographs, PNG for graphics)
- Include proper alt text in HTML
- Consider responsive image sizes
